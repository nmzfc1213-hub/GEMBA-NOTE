# GEMBA-NOTE — 見積もり・原価・3Dの統合ワークスペース

公開URL：https://gemba-note-exterior.nmzfc1213.chatgpt.site

既存「現場ノート」の見積もり・原価管理・単価表・平面図・参考写真・提出前チェックを、新しい自由配置3Dエディターと統合した開発版です。元サイト・元DBには変更を加えません。

## 操作

1. 「案件・見積もり」で案件を選ぶか「新しい案件」を作成。
2. 現場情報、工事項目、費用・利益、提出準備の順に入力。コンクリートは面積・厚み・メッシュ・生コン・人工を分けて計算。
3. 「この案件の3Dプランを編集」で住宅・敷地・車・外構を編集。「見積もり・案件へ」で戻る。
4. 見積と3Dは同じ案件に保存。単価ライブラリ、原価・粗利比較、平面図・寸法メモ、参考写真、提出チェックへ切り替えられます。
5. 「全データをバックアップ」で見積・単価・写真・3DをまとめてJSONに書き出せます。

3D寸法から見積明細の数量への自動連動は行いません。図面・数量・施工条件を確認して明細に入力してください。

## 保存と移行

**統合版は各訪問者のブラウザに自動保存します。クラウド同期はありません。** 別端末へ移る場合や大事な変更後にはJSONを書き出してください。公開URLで所有者の案件や写真が他人に表示されることはありません。

- 統合保存キー：`gemba-note:workspace:v1`。
- 以前の3D保存キー `genba-exterior-studio:v1` は保持。「以前の3D保存を取り込む」から案件に追加できます。
- 元の現場ノートでJSONバックアップを書き出し、統合版の「バックアップから追加読込」で案件・単価・写真・旧3Dを読み込めます。読み込み時は新しいIDを付け、既存の案件・単価・基本設定を上書きしません。
- 単体3DのJSONも案件に追加できます。
- 元のクラウドDBの内容を自動取得・移動する機能はありません。旧3Dは建物・土間・車・カーポートを変換し、その他の素材・配置は再設定が必要です。
- 保存が壊れている場合は上書きを止めます。容量・権限エラーは画面に表示します。写真は1案件6枚まで縮小保存。

## 開発

Node.js 22以上。

```sh
npm ci
npm run dev
npm test
npm run build
```

React 19 / Vite / Three.js。静的配布。GitHub Actionsでもテストとビルドを実行します。`.openai/hosting.json` はこの統合版専用のSite IDです。既存サイトのID・DBを使わないでください。

`src/Office.tsx` と `components/`、`lib/` は元サイトのコードを再利用。3Dは `src/Editor.jsx`・`Viewport.jsx`・`scene.js`・`model.js`。`src/LinkedEditor.jsx` が案件への紐付けを担います。`src/workspace/store.js` が追加読込・検証・保存を担当。

事務画面と3D画面のスタイルは `styles/*.raw.css` から `scripts/scope-styles.mjs` でスコープを付けて生成。3Dは別ポータルに表示し、事務画面のCSSから分離します。

## 検証と制限

47件の自動テスト：見積・コンクリート計算、単価取り込み、敷地と車の寸法、バックアップ移行、見積→3D→見積の画面遷移、保存・再読込等。DOMテストはjsdomによるもので、実ブラウザのWebGL・タッチ操作・PNGダウンロード・見た目は未検証です。

車・住宅は汎用の独自生成モデルで、写実性の改善が必要です。施工可能性、構造安全性、法令適合は保証しません。地盤は一枚の勾配面で、配置物は中心の地盤高を基準に水平に置きます。自動の干渉・旋回・構造判定はありません。
