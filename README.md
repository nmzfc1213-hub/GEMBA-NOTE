# GEMBA-NOTE — 現場ノート 外構スタジオ

既存の現場ノートを保護しながら開発する、独立した外構3Dエディターです。**開発版・本番未公開**。施工可能性・構造安全性・法令適合を保証しません。

GitHubへの初回アップロードは接続の新規リポジトリ作成権限が不足して未完了です。コードはローカルGitに記録済み。所有者が非公開の空リポジトリを用意し、GitHub連携に許可後、専用リポジトリにpushします。既存リポジトリは変更していません。

## 起動

Node.js 22以上。

```sh
npm ci
npm run dev
```

テストは `npm test`、配布用ビルドは `npm run build`。`dist/` を静的ホスティングに配置できますが、本番公開は所有者の承認後に実施してください。外部API、有料サービス、既存SitesのDBへの接続はありません。

## 操作

- 「配置」から住宅、4車種、カーポート、門柱、フェンス、擁壁、階段、デッキ、芝、砂利、コンクリート、タイル、植栽を追加。
- 3Dビューか一覧で選択し、プロパティで位置・寸法・角度を編集。「移動」モードでドラッグし、指を離すと確定。
- 「敷地」で長方形、台形、旗竿地、L字、角地を適用。頂点のドラッグ・座標入力・追加・削除で自由な多角形を編集。
- 住宅は総2階、平屋、L字、コの字、凹凸形状。切妻、片流れ、陸屋根、外壁色、窓・玄関の表示を変更可能。
- 真上・正面・斜めの視点、ピンチ拡大、軽量／高画質、太陽高度、敷地寸法、PNG保存に対応。
- 「案件を保存」でこの端末のブラウザに保存。「案件」から再編集。JSONは別端末への移行とバックアップに使用。
- 既存の現場ノートのJSONを読み込むと、最初に見つかった3D案件の建物、土間、車、カーポートを新規案件に変換。既存ファイルは変更しません。素材、通路、デッキ等の完全移行には未対応です。

保存キーは `genba-exterior-studio:v1`。既存の保存キーを利用しません。保存容量や権限の問題が発生した場合はJSONを書き出してください。クラウド同期は未実装です。

## 寸法

1 Three.js単位 = 1m。X/Zが水平、Yが高さ。回転はY軸の度数。敷地面積・辺長は水平投影値です。勾配は `%` から `高さ = 基準高 + X×勾配X/100 + Z×勾配Z/100` で生成します。

住宅の幅・奥行きは外壁の外接矩形、高さは軒高です。屋根高は加算されます。車両は外形寸法とメッシュの境界寸法を自動テストで照合しています。ミラーや施工余裕を含むメーカー車両寸法ではありません。

敷地は一枚の勾配面。配置物は中心の地盤高を基準に水平配置し、Yオフセットで段差を設定します。地形切盛り、曲面地形、構造設計、屋根と壁の個別頂点編集、窓と玄関の個別配置、製品CAD連携、干渉・旋回解析には未対応です。外接矩形の敷地外のみ警告します。

## 品質の現状

自動テストと本番ビルドを実施。ブラウザ操作ツールがこの実行環境に提供されなかったため、実機のタッチ操作、PNGのダウンロード、WebGL画面、保存・再読込の一連の操作は未検証です。公開前に [受入テスト](docs/ACCEPTANCE.md) を実施してください。

モデルは独自生成の汎用モデルです。窓、ホイール、ランプ、グリル、屋根、フェンス等の操作可能な3D形状を実装していますが、写実的な市販車・住宅モデルの品質には達していません。商談での本格運用には素材の追加改善と実機確認が必要です。
