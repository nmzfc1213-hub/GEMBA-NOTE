# 統合版の変更と保存設計

2026-11-10、ユーザーの統合指示に基づき、既存ソースの事務機能を新規サイトへ移植。

## 引き継いだ機能

ダッシュボード、会社別案件、見積4ステップ、原価・工務店価格・客出し価格、旧粗利率方式、コンクリート積上げ、単価ライブラリ、Excel・CSV・TSV取り込みと履歴、原価・粗利比較、平面図メモ、参考写真、提出前チェック。

`lib/pricing.ts` と `lib/rate-import.ts` の計算・取り込み動作は元コードを引き継ぎ、元テスト25件を移設。

## 3Dの紐付け

各Projectに `editorScene` を追加。旧 `scene` は保持し、3Dを開くと必要に応じて変換。`LinkedEditor` は対象案件IDをキーに3Dを表示。確定した変更を同じ案件へ反映し、戻っても状態が残る。元の会社・見積計算方式・単価の控えは変更しない。3Dの面積と見積数量の自動連動は未実装。

## データ保護

元API `/api/workspace` への通信を除去し、新規のlocalStorageキーに保存。公開サイトの閲覧者間で保存内容を共有しない。旧スタンドアロン3Dの保存キーも読み取りのみに使用。追加読込は案件・単価IDを付け替え、明細のrateIdも新IDへ対応付ける。既存案件と基本設定は保持。

新規バックアップのサイズは12MBまで、案件100件、単価10000件、写真1案件6枚。保存容量は端末のブラウザに依存。エラー時は成功表示にせず、JSON退避を案内。壊れた保存データは上書きしない。

## 検証

47自動テストと本番ビルド。DOMテストで案件名の変更、同案件3Dの部材追加、保存、見積へ戻る、再マウントからの復元を確認。単価・原価・図面・写真・提出チェックのナビゲーションも確認。実ブラウザの描画・スマホ操作は別途受入テストが必要。
