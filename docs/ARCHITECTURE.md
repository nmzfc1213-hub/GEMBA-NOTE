# 設計と対応状況

React 19 + Three.js + Vite。静的配布できる独立エディター。元Sitesのサーバー・認証・D1へ依存しない。

- `src/model.js`：メートル座標の案件スキーマ、形状テンプレート、面積、回転外形、勾配、境界チェック、JSON検証、旧3D変換。
- `src/scene.js`：共通寸法から生成する住宅・車両・外構モデル、屋根、勾配付き敷地、照明用マテリアル、寸法ラベル、GPUリソース解放。
- `src/Viewport.jsx`：長寿命のWebGLレンダラーとカメラ、OrbitControls、選択、ドラッグ移動、PNG、必要時のみ描画。
- `src/main.jsx`：頂点編集、数値プロパティ、50操作のUndo/Redo、端末保存、ファイル入出力、スマホ向けレイアウト。

## 残る優先課題

1. 既存サイトのログイン後の実画面確認と、新エディターのデスクトップ・スマホでの受入テスト。
2. 車両・住宅の写実性の改善。外部モデル導入時は、商用利用、再配布、改変、クレジット、商標の条件を素材ごとに記録。未確認素材は採用しない。
3. 窓・玄関の個別編集、自由ポリゴンでの素材敷分け、局所地盤編集。
4. 複数プラン比較、衝突・旋回の補助表示、単位・スナップ操作の改善。
5. 承認された新規の保存バックエンドへのクラウド保存・認証。既存DBを共有しない。

これらの未完了項目があるため、現時点を商談用完成版とは扱わない。本番公開承認を求める前に、実機検証とモデル品質の改善を行う。
